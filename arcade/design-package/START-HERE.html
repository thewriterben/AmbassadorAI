How to work with this

1 · App shell
The DGD phone app around the arcade: the ticker, Arcade menu, log in, join, membership and invite screens, the app icon (Android and iOS) and the Play Store icon.
2 · In-app arcade
Coin Quest as it plays inside the phone app: coins, obstacles, board, map, backgrounds, sounds and Quest Tune.
3 · Web arcade
digitalgold.co/arcade: Coin Quest and When Pigs Fly in the browser, the boar sprite sheets, pickups, browser icons, the rules page and all sounds.
Replacing a file
Keep the path and name, keep the pixel size shown below. Many files are identical in both arcades; those are marked, and one design replaces both.
Changing a screen
Most screens are drawn in code, not from images. Send a mockup (PNG, PDF or Figma) in mockups/ and it will be built to match.
Sending it back
One zip, same folders, only changed files, plus CHANGES.txt. Full rules in RETURN-SPEC.md, including icon, sprite and audio formats and the few things that must stay true.

Worth designing first

Web arcade icons are placeholders
The favicon and home-screen icons are still Flutter's blue logo, and manifest.json still says "A new Flutter project" in blue. Needs a DGD icon set.
Two palettes on the web
The rules page uses its own CSS colours (accent #f0a032) while the arcade uses the brand #EA952D. Worth unifying.
Two type systems
The arcades use Instrument Sans, Geist Mono and PT Serif; the app shell uses the phone's own Roboto and serif. A decision either way would help.
Results in the app are quieter
Inside the DGD app the win screen has no fireworks or winner voice line (a compliance rule). A celebration that fits within that is open for design.
When Pigs Fly boar
New drawn poses for all three boar stages are already in progress separately. Please check before redrawing the boar sheets.
